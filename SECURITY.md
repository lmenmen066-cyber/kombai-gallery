# Security Policy

## Reporting a vulnerability

Please open a **private security advisory** on this repository (Security → Report a
vulnerability) rather than posting details in a public issue. We aim to acknowledge
reports within a few business days.

## Scope

This is a design-system showcase. The production app it models is out of scope here.

## Supported versions

The current default-branch build is the supported one. Dependency updates are handled
automatically via Dependabot.
